# BUILD_PLAN_WEB.md — Table Talkers (웹 전환 후)

2026-07-04 웹 피벗 기준 실행 계획. 규칙·불변식은 루트 `CLAUDE.md` 참조.
Unity 트리는 동결된 프로토타입. 활성 개발 = `web/`.

## W0. 스캐폴드 ✅(진행 중)
Vite+TS+Three.js 프로젝트, 시그널링 서버, 코지 라운지 씬, 착석 카메라.
- 완료 기준: `npm run dev`로 라운지가 브라우저에 뜨고 고개를 돌릴 수 있다.

## W1. 방 + 연결 (M0 전반)
방 코드 생성/링크 입장(#r=코드), WebRTC 메시(신규 입장자가 기존 피어에 오퍼),
데이터 채널(ctrl/pose), 호스트 좌석 배정, 헤드 yaw/pitch 15Hz 동기화 + 원격 보간.
- 완료 기준: 탭 2개에서 서로의 아바타 머리가 따라 움직인다.

## W2. 음성 (M0 완성)
getUserMedia(AEC/NS/AGC) → 트랙 교환, 피어별 WebAudio(레벨 분석→입/링, 좌석 방향 팬, 뮤트/볼륨),
VoiceService 인터페이스 뒤에 격리. 디버그 오버레이(RTT/참가자/레벨).
- 완료 기준(M0 게이트): 탭 2개(또는 2기기)로 서로 보며 대화. 🔧 사람: 실제 마이크 체감.

## W3. 존재감 + UX (M1 전반)
생명감(깜빡임/숨/입), 이모트 5종(ctrl 일회성 + 연출 + 라벨), 이름표, 입장/퇴장 토스트,
힌트바, 마이크 설정(PTT/음성감지, 피어 볼륨/뮤트), 텍스트 채팅.

## W4. 배포 + 외부 테스트 (M1 게이트)
시그널링 무료 티어 배포, 정적 호스팅(예: GitHub Pages/Cloudflare), HTTPS(마이크 권한 필수),
버전 게이트. 🔧 사람: 링크만 받은 친구 1명 접속 테스트 → 4인 15분 대화.

## W5+. 제품화 (이후)
안전(차단/신고+수신 백엔드), 온보딩 다듬기, 법무 문서/링크, 애널리틱스,
호스트 결제(MoR) → 방 격상, 진짜 아바타(RPM 웹), 좌석 8~12, 모바일 대응.

### 알려진 한계 (의도된 MVP 트레이드오프)
- TURN 없음: 일부 회사/기숙사 NAT에서 연결 실패 가능 → W4에서 측정 후 결정.
- 호스트 이탈 = 방 종료(마이그레이션 후순위).
- 메시 구조는 ~8인까지: 그 이상은 SFU 검토(설계상 상한 12).
