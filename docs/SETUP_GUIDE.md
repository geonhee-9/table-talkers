## ▶️ 다음 할 일: 혼자서 첫 실행

1. **스팀 켜기** — 맥의 Steam 앱 실행, 로그인 상태 확인.
2. Unity에서 Project 창 → `Assets > TableTalkers > Scenes > Boot` **더블클릭**.
3. 위쪽 **▶️ 재생 버튼** 클릭.
4. 처음이면 **마이크 체크 창**이 뜸 → 따라 하고 완료.
5. 왼쪽 위 **`Create Room`** 버튼 클릭.
6. **성공 판정:** 시점이 의자에 앉은 1인칭으로 바뀌고,
   F1 디버그 창에 내 이름이 `seat 0` 으로 뜬다.

> 안 되면: Console(콘솔)의 빨간 줄을 복사해서 Claude Code에 붙여넣기.

## 🧪 그 다음: 진짜 테스트 (M0 게이트)

컴퓨터 2대 + 서로 친구인 스팀 계정 2개 필요.

1. Unity 메뉴 `File > Build Profiles` → **Build** 로 실행파일 생성.
2. 두 번째 컴퓨터에 복사 (그 컴퓨터도 스팀 로그인).
3. A: `Create Room` → `Invite Friends` 로 B 초대.
4. B: 스팀 알림에서 수락 → 자동 입장.
5. **통과 조건:** 서로 아바타가 보이고, 고개 움직임이 상대 화면에 보이고, 음성 대화가 된다.

- 공간 음성(ODIN) → SDK 임포트 후 설정 하나로 전환
